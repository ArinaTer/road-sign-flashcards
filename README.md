# Знак за знаком

Тренажёр дорожных знаков Узбекистана на Vue 3 и Vite. В проект входят 305 карточек из восьми групп. Изображения хранятся локально, результаты сохраняются в `localStorage` текущего браузера.

## Запуск

Требуется Node.js 20.19+ или 22.12+.

```sh
npm ci
npm run dev
```

Откройте [http://127.0.0.1:8765/](http://127.0.0.1:8765/). Этот адрес совпадает с адресом прежней версии, поэтому сохранённый на нём прогресс доступен и в Vue-приложении.

Для статической сборки выполните `npm run build`. Готовые файлы попадут в `dist/`. Для локальной проверки сборки остановите сервер разработки и выполните `npm run preview`.

## Структура проекта

- `src/views/` — экраны выбора обучения, раунда и результатов.
- `src/components/` — компоненты интерфейса со стилями внутри `.vue`-файлов.
- `src/composables/` — состояние обучения и сохранение прогресса.
- `src/domain/` — каталог, отбор карточек, расписание повторений и формат хранения.
- `src/content/` — тексты интерфейса в JSON по компонентам. В `src/content/groups/` у каждой группы свой файл с названием и карточками.
- `public/signs/` — изображения в папках групп. Имя файла совпадает с постоянным ID знака в каталоге.

Каталог и краткие пояснения подготовлены по материалам [PDDTest](https://pddtest.uz/znaki/). Часть изображений взята из каталога [Uzavtoyo‘lbelgi](https://uzavtoyolbelgi.uz/dorojnie/znaki) и из официальных таблиц [ПДД Узбекистана](https://lex.uz/ru/docs/5953887#7716946). Нажмите на карточку, чтобы увидеть номер, группу, название и пояснение. Смахните открытую карточку вправо, если знаете знак, или влево, если хотите его изучить. Кнопки под карточкой записывают те же ответы.
